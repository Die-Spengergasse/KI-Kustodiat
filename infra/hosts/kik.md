## DNS-Suchdomänen (`/etc/resolv.conf`)

`kik` hat weder `resolvconf` noch `systemd-resolved` noch einen laufenden
DHCP-Daemon — `/etc/resolv.conf` ist ein statisches, handgepflegtes File (der
Header „Generated by dhcpcd" ist Altlast). Aktueller Inhalt:

```
nameserver 10.50.5.11
nameserver 10.50.5.18
search htl-wien5.schule spengergasse.at
```

Die Suchdomäne `htl-wien5.schule` ist **nötig**, damit `gregor.kik` auflöst
(`gregor.kik.htl-wien5.schule` → `10.50.11.10`, der Whisper-STT-Host). nginx
löst `proxy_pass`-Hostnamen beim Config-Load via `getaddrinfo` auf — die
Suchdomäne muss daher **vor** `nginx -t`/Reload gesetzt sein, sonst schlägt der
Start fehl („host not found in upstream"). `spengergasse.at` erlaubt Kurznamen
wie `kik`. Backup der Originalfassung: `/etc/resolv.conf.bak-<ts>`.

## Angebots-Job (2026-10-11, Issue #32)

`update-offers.timer` (systemd, montags 06:00, `Persistent=true`) startet
`update-offers.service` → `scripts/run-offers-job.sh`: opencode-Websuche (Skill
`update-offers`) → `website/content/angebote.md` → Commit/Push → rsync auf
`/var/www/kik`. Läuft als User `grafg`; Deploy nutzt das passwortlose `sudo`.
Referenzkopien der Units: `infra/systemd/`. Installiert per
`systemctl enable --now update-offers.timer`.

- **opencode headless** braucht `HOME=/home/grafg` (Credentials in
  `~/.local/share/opencode/opencode.db`, Provider `opencode-go`/`opencode`).
- **Modell gepinnt:** `--model opencode-go/deepseek-v4.1-flash#high` im Runner
  (Issue #33). Ohne Pin nutzt opencode das *neueste Katalogmodell* — der Job
  lief zuvor still auf `claude-haiku-5-5`. Der globale Default `model` in
  `~/.config/opencode/opencode.json` ist zusätzliches Sicherheitsnetz.
- `opencode run` endet mit Exitcode 1, sobald im Lauf Tool-Fehler auftraten —
  das Skript fängt das ab und entscheidet am Artefakt.
